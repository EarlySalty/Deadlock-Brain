# Review S01 bis S09 vom 24.09.2026

## Ergebnis

S01 ist als Inventar übernommen. S02 bis S09 besitzen jetzt einen kompilierenden Rust Durchstich für Vertrag, Policy, Storage, Datei Ingestion, Aliasnormalisierung, Retrieval, Provider und Jev Validierung, Answer Kernel, API Handler und typisierten Client.

## Im Review behobene Befunde

* S03: Ein Corpus Release hatte zuvor je Quelle lediglich die höchste Revisionsnummer gespeichert. Der Vertrag speichert jetzt je Quelle und logischer Dokument ID die konkrete Revision, damit ein Release reproduzierbar bleibt.
* S06 und S02: Interne oder private Evidenz mit leerer Scope Liste war durch die Mengenprüfung faktisch freigegeben. Policy und Retrieval verhalten sich jetzt fail closed und besitzen negative Regressionstests.
* S07: Retry Anzahl, Antwortlänge und Provider Timeout waren nicht vollständig an das autorisierte Request Budget gekoppelt. Netzwerk Runden, Ausgabetokens und Deadline begrenzen jetzt den Aufruf vor und während der Provider Kommunikation.
* S05: Die Aliasnormalisierung besitzt einen expliziten v1 Vertrag. Randtrenner und Steuerzeichen werden stabil behandelt, die Funktion ist idempotent und Unicode Buchstaben werden nicht still in ASCII transliteriert.

## Verifikation

Gezielte Rust Suite: 88 Tests erfolgreich, 21 explizit ausgelassen, 0 fehlgeschlagen.

Clippy für die geänderten Pakete mit Warnungen als Fehler: erfolgreich.

Workspace Check über sämtliche Targets: erfolgreich.

Git Diff Prüfung auf Whitespace Fehler: erfolgreich.

## Noch offene Abnahmen

Die ausgelassenen Prüfungen benötigen eine isolierte Scratch Postgres Instanz beziehungsweise den versionierten echten Game Wiki Bestand. Der PR first Testbetrieb erlaubt in diesem Auftrag keinen produktiven Datenlauf, keinen Dienstneustart und keinen Cutover.

S09 stellt den zentralen Rust Client und den API Vertrag bereit. Die Umschaltung externer Consumer Repositories erfolgt erst gegen einen integrierten und isoliert getesteten API Stand, damit kein Consumer einen ungeprüften Schattenpfad erhält.
