# K2 approved acceptance boundary

The task's explicit architecture approval is: "Approved: the grammar boundary, not model-trusted completeness."

- Final model answers use structured parts. Prose contains no numeric characters. Numeric literals belong to evidence-bound value slots.
- Game values require recognized game authority and exact evidence ID, field and value matching. Approved metadata fields may use `other` slots. A rendered numeric literal must be wholly contained in one validated value slot; joining values, signs, decimal punctuation, grouping or exponents must not manufacture a different literal.
- Social answers use the structured `social` signal, only prose and no citations. They can be answered without game evidence.
- Spelled-out German numbers are explicitly outside the approved scope. No semantic free-text game-claim detector or number-word dictionary was approved. This contract does not certify the semantic truth of surrounding prose.
- Cited uncertain community coaching remains answerable without invented hard numeric literals. The existing Fact/Build pre-model guard remains in force.
- ACL, provider egress, receipts, publication, exposure, accounting and budgets are unchanged. Ambient Discord evidence cannot authorize game values.
- Acceptance includes at least twenty real question types through the configured central provider. Format-induced silence is measured separately from evidence and value silence. Format silence above ten percent requires escalation before merging.

This document records the scoped K2 approval for independent review. It does not waive the local merge gate or authorize a merge, release, model change or new semantic detector.
